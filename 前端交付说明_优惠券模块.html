优惠券模块 — 前端对接说明

交付对象：前端 · 版本：2026-10-02 · 对应后端分支 2026-10-02 · 接口文档同步至 v8.8 §98

一、先看结论

  • 优惠券不再是商品，改成独立功能模块；原商品「优惠券10元」已下架（status=inactive），前端不要在商品列表里再展示优惠券商品。
  • 用户端新增 4 个接口：GET /coupons/center（领券中心）、POST /coupons/{templateId}/claim（领取）、GET /coupons/my（我的券）、GET /coupons/available（下单可用券）。
  • 下单链路接入：试算和支付两个接口新增 userCouponId 入参；响应新增 couponId / couponAmount 出参。
  • 抵扣只作用于商品金额，不抵扣配送费。

二、业务口径

维度取值与说明
券类型 type full_reduction 满减 · discount 折扣 · instant_reduction 立减
适用范围 scope platform 平台券（全平台通用） · merchant 商家券（限指定商家，字段 merchantId）
到账方式 source claim 领券中心自助领取 · grant 商家/平台定向发放
有效期 validType fixed 固定起止（validStartAt/validEndAt） · relative 领取后 N 天（validDays）
使用门槛 minSpendAmount 订单商品金额（不含配送费）需 ≥ 该值，否则不可用

抵扣计算规则

券类型抵扣额
满减 / 立减min(valueAmount, 商品金额)
折扣min(商品金额 × (10 − discountRate) / 10, maxDiscountAmount, 商品金额)
未达门槛0（不可用）

折扣率写法：8.5 表示 8.5 折（即抵扣 15%）。

三、券状态机（前端展示用）

状态含义前端建议文案
unused可用立即使用
locked已锁定（下单支付中）支付中
used已核销已使用
expired已过期已过期
订单取消或超时未支付，券会自动释放回 unused，前端刷新「我的券」即可看到。

四、用户端接口

4.1 领券中心 GET /coupons/center

GET /api/v1/coupons/center?merchantId=mch_xxx
Auth: Required   Roles: resident
merchantId 可选：只看某商家的商家券

返回可领取的券模板数组。关键字段：id(cpt_)、name、type、scope、merchantName、valueAmount、discountRate、maxDiscountAmount、minSpendAmount、validType、validStartAt、validEndAt、validDays、totalQuantity、claimedQuantity、remainingQuantity、perUserLimit、claimedByMe。

claimedByMe=true 表示当前用户已达领取上限，前端应把「领取」按钮置灰。

4.2 领取 POST /coupons/{templateId}/claim

POST /api/v1/coupons/cpt_xxx/claim
Auth: Required   Roles: resident
Body: 无

返回 UserCouponResponse（结构见 4.3）。领取失败错误码：60047 已领完 / 60048 超每人限领 / 60049 不可领取（非 active 或范围不可见）。

4.3 我的优惠券 GET /coupons/my

GET /api/v1/coupons/my?status=unused
Auth: Required   Roles: resident
status 可选：unused / locked / used / expired，不传=全部

返回用户券数组：

字段类型说明
idString用户券 ID（ucp_ 前缀，下单选券时回传此值）
templateIdString券模板 ID
nameString券名称
type / scopeString券类型 / 券范围
merchantId / merchantNameString限定商家（平台券为 null，字段会整个不返回）
valueAmount / discountRate / maxDiscountAmount / minSpendAmountBigDecimal面额快照（同模板）
statusString券状态
sourceStringclaim 领取 / grant 发放
expireAtString过期时间
claimedAt / usedAtString到账时间 / 核销时间
orderIdString核销订单 ID
expiredBoolean按当前时间计算的过期标记

4.4 下单可用券 GET /coupons/available

GET /api/v1/coupons/available?merchantId=mch_xxx&productAmount=100.00
Auth: Required   Roles: resident
merchantId 必填；productAmount 为订单商品金额（不含配送费）

返回可用券数组（按可抵扣金额倒序），元素含 id(ucp_)、name、type、scope、merchantId、面额快照、expireAt、discountAmount（本单可抵扣金额）、usable（是否满足门槛）。

未达门槛的券也会返回，但 discountAmount=0、usable=false，前端应置灰并提示"未达使用门槛"。

五、下单流程接线（重点）

1. 进入下单页
   GET /coupons/available?merchantId=xxx&productAmount=商品金额
   → 渲染可用券列表

2. 用户选券
   POST /orders/preview   （或 POST /orders/from-listing/preview）
   body 增加 "userCouponId": "ucp_xxx"
   → 响应返回 couponId / couponAmount / cashAmount（最终应付现金）

3. 支付
   POST /orders/{id}/pay
   body 增加 "userCouponId": "ucp_xxx"
   → 响应返回 couponAmount

4. 订单查询
   GET /orders/my 或 GET /orders/{id}
   → 响应含 couponId / couponAmount（订单详情展示优惠明细）

5.1 试算接口新增字段

接口入参新增出参新增
POST /orders/preview（§8.0）userCouponId（选填）couponId、couponAmount
POST /orders/from-listing/preview（§8.0.0）userCouponId（选填）couponId、couponAmount
POST /orders/{id}/pay（§8.2）userCouponId（选填）couponAmount
试算只是"预览"，不会锁定券；真正锁定发生在 pay。券无效/不适用时 couponAmount=0，不报错。
cashAmount 计算口径：totalAmount − couponAmount − coinUsed − pointUsed折算值，最低 0。

七、管理端接口（管理后台用）

Roles：platform_admin、property_admin。平台券仅 platform_admin 可创建/管理；property_admin 仅能管理本物业的商家券。

方法路径说明
GET/admin/coupons模板列表（分页，支持 scope/status/merchantId/propertyCompanyId 过滤）
GET/admin/coupons/{id}模板详情
POST/admin/coupons创建模板
PUT/admin/coupons/{id}更新模板（已发放后禁改面额/门槛）
PUT/admin/coupons/{id}/status启用/停用，body {"status":"active"|"inactive"}
POST/admin/coupons/grant定向发放

创建模板请求体

{
  "name": "满100减20",
  "description": "仅限本店使用",
  "type": "full_reduction",        // full_reduction | discount | instant_reduction
  "scope": "merchant",             // platform | merchant
  "merchantId": "mch_demo002",     // scope=merchant 必填
  "valueAmount": 20.00,            // 满减/立减必填
  "discountRate": null,            // 折扣券必填（8.5=8.5折）
  "maxDiscountAmount": null,       // 折扣券可选封顶
  "minSpendAmount": 100.00,        // 门槛，默认 0
  "validType": "relative",         // fixed | relative
  "validStartAt": null,            // fixed 必填 "yyyy-MM-dd HH:mm:ss"
  "validEndAt": null,              // fixed 必填
  "validDays": 30,                 // relative 必填
  "totalQuantity": 1000,           // 不传=不限量
  "perUserLimit": 1,               // 必填
  "status": "active"
}

定向发放请求体

POST /admin/coupons/grant
{
  "templateId": "cpt_xxx",
  "residentIds": ["res_001", "res_002"],
  "quantity": 1          // 每人发放张数，默认 1
}
// 响应：{ "grantedCount": 2 }

八、商家端接口（商家工作台用）

Roles：merchant（商家身份由登录态解析）。

方法路径说明
GET/merchant/coupons本商家券模板列表（仅 scope=merchant 且属于本商家）
POST/merchant/coupons/grant发放本商家券（body 同管理端）
商家只能发放自己的商家券；发放平台券或他人券返回 PERMISSION_DENIED。

十、前端注意事项

  • 全局 Jackson 配置 default-property-inclusion=non_null：值为 null 的字段不会出现在 JSON 中，不是返回 null。例如平台券的 merchantId/merchantName 会"整个消失"，前端判空请用 !field 而非 field === null。
  • 优惠券只抵扣商品金额，不抵扣配送费；配送费结算不受影响。
  • 试算不锁券、支付才锁券；订单取消/超时未支付券会自动释放，刷新「我的券」即可。
  • 不要在下单页用 discountAmount 自行计算最终应付现金，应以 POST /orders/preview 返回的 cashAmount 为准（后端还会叠加物业币/积分规则）。
  • 商品列表不要再展示原「优惠券10元」商品（已下架 status=inactive）。
