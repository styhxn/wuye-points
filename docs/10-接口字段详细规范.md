> **版本**：v1.0
> **日期**：2026-07-01
> **适用范围**：小程序端核心接口（约 45 个）
> **配套文档**：`02-数据库设计.md`（49张表）、`前后端对齐规范.md`（API契约）、`09-Web后台API设计.md`（后台接口）

## 1. 概览

### 1.1 命名规范

| 层面 | 命名风格 | 示例 |
|------|---------|------|
| 数据库字段 | `snake_case` | `property_company_id`、`created_at` |
| API 请求/响应字段 | `camelCase` | `propertyCompanyId`、`createdAt` |
| URL 路径 | 小写 + 连字符 (kebab-case) | `/api/v1/property-fees/:id` |
| 枚举值 | 小写 + 下划线（字符串常量） | `official_certified`、`pending` |

后端通过 Jackson `PropertyNamingStrategy` 自动完成 snake_case ↔ camelCase 映射，前端直接使用 camelCase。

### 1.2 空值处理

| 场景 | 规范 | 示例 |
|------|------|------|
| 字段不存在/未设置 | 返回 `null` | `"avatarUrl": null` |
| 列表为空 | 返回空数组 `[]` | `"items": []` |
| 数值为空 | 返回 `null`（区分于 0） | `"balance": null` |
| 字符串为空 | 返回 `""`（有内容但为空）或 `null`（无内容） | `"remark": ""` |

### 1.3 统一响应格式

所有接口响应必须使用以下统一结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "timestamp": "2026-07-01T10:00:00.000Z"
}
```

列表响应统一含 `pagination` 对象：

```json
{
  "code": 0,
  "data": {
    "list": [ ],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 156,
      "totalPages": 8
    }
  },
  "timestamp": "2026-07-01T10:00:00.000Z"
}
```

### 1.4 分页与排序

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | number | 1 | 当前页码（从 1 开始） |
| `pageSize` | number | 20 | 每页条数（最大 100） |
| `sort` | string | `-createdAt` | 排序字段（`-`降序，`+`升序），多字段逗号分隔 |

## 2. 认证模块

### 2.1 POST `/api/v1/auth/wechat-login` 微信登录

**鉴权**：Optional（无需 Token）
**说明**：小程序前端通过 `wx.login()` 获取 `code`，提交后端换取 OpenID 并签发 JWT。

#### 请求参数（Body）

| 字段 | 类型 | 必填 | 校验规则 | 说明 | 示例 |
|------|------|------|---------|------|------|
| `code` | string | 是 | 非空，长度 ≤ 256 | 微信小程序 wx.login 返回的 code | `"0a3xPP000xxx"` |
| `encryptedData` | string | 否 | — | 微信用户信息加密数据（可选，用于获取头像昵称） | `"Ciy8G..."` |
| `iv` | string | 否 | 长度 24 | 加密向量，与 encryptedData 配套 | `"r7B2..."` |
| `propertyCompanyId` | string | 否 | 前缀 `pc_` | 用户所属物业公司ID（首次登录指定） | `"pc_a8f3k2"` |

#### 响应字段（data）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `accessToken` | string | 访问令牌（有效期 1 小时） | `"eyJhbGci..."` |
| `refreshToken` | string | 刷新令牌（有效期 7 天） | `"eyJhbGci..."` |
| `expiresIn` | number | Access Token 过期秒数 | `3600` |
| `tokenType` | string | 令牌类型 | `"Bearer"` |
| `resident` | object | 用户基本信息 | 见下 |
| `resident.id` | string | 用户ID | `"res_b7m9x1"` |
| `resident.name` | string/null | 姓名 | `"张先生"` |
| `resident.avatarUrl` | string/null | 头像URL | `"https://cdn..."` |
| `resident.phone` | string/null | 手机号（已脱敏） | `"138****1234"` |
| `resident.role` | string | 角色 | `"resident"` |
| `resident.propertyCompanyId` | string | 物业公司ID | `"pc_a8f3k2"` |
| `resident.communityId` | string/null | 小区ID | `"com_b7m9x1"` |
| `resident.familyId` | string/null | 家庭ID | `"fam_h4j7k2"` |
| `resident.wechatBound` | boolean | 是否已绑定微信 | `true` |
| `resident.newUser` | boolean | 是否新用户 | `false` |
| `resident.status` | string | 账号状态 | `"active"` |

#### 请求示例

```bash
curl -X POST https://api.example.com/api/v1/auth/wechat-login \
  -H "Content-Type: application/json" \
  -d '{
    "code": "0a3xPP000xxx",
    "propertyCompanyId": "pc_a8f3k2"
  }'
```

#### 成功响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expiresIn": 3600,
    "tokenType": "Bearer",
    "resident": {
      "id": "res_b7m9x1",
      "name": "张先生",
      "avatarUrl": "https://cdn.example.com/avatar/res_b7m9x1.jpg",
      "phone": "138****1234",
      "role": "resident",
      "propertyCompanyId": "pc_a8f3k2",
      "communityId": "com_b7m9x1",
      "familyId": "fam_h4j7k2",
      "wechatBound": true,
      "newUser": false,
      "status": "active"
    }
  },
  "timestamp": "2026-07-01T10:00:00.000Z"
}
```

#### 错误响应示例

```json
{
  "code": 30003,
  "message": "微信授权失败",
  "data": null,
  "timestamp": "2026-07-01T10:00:00.000Z"
}
```

可能错误码：`10001`（参数缺失）、`30003`（微信授权失败）、`20005`（账号被禁用）、`99001`（内部异常）。

### 2.2 POST `/api/v1/auth/refresh-token` 刷新 Token

**鉴权**：Optional
**说明**：Access Token 过期时，前端拦截 401 后自动调用此接口。

#### 请求参数（Body）

| 字段 | 类型 | 必填 | 校验规则 | 说明 | 示例 |
|------|------|------|---------|------|------|
| `refreshToken` | string | 是 | 非空，JWT 格式 | 刷新令牌 | `"eyJhbGci..."` |

#### 响应字段（data）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `accessToken` | string | 新的访问令牌 | `"eyJhbGci..."` |
| `refreshToken` | string | 新的刷新令牌（滚动续期） | `"eyJhbGci..."` |
| `expiresIn` | number | 过期秒数 | `3600` |
| `tokenType` | string | 令牌类型 | `"Bearer"` |

#### 请求示例

```bash
curl -X POST https://api.example.com/api/v1/auth/refresh-token \
  -H "Content-Type: application/json" \
  -d '{ "refreshToken": "eyJhbGci..." }'
```

#### 成功响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
    "expiresIn": 3600,
    "tokenType": "Bearer"
  },
  "timestamp": "2026-07-01T10:00:00.000Z"
}
```

可能错误码：`20002`（Refresh Token 过期）、`20003`（Token 无效）。

#### 响应字段（data）

| 字段 | 类型 | 说明 | 示例 |

| `bound` | boolean | 是否绑定成功 | `true` |

```json
{

  "data": {

    "bound": true,

}
```

## 附录 B：通用字段说明

### B.1 时间字段

所有时间字段统一使用 ISO 8601 UTC 格式：`YYYY-MM-DDTHH:mm:ss.SSSZ`

| 字段 | 说明 |
|------|------|
| `createdAt` | 创建时间 |
| `updatedAt` | 更新时间 |
| `publishedAt` | 发布时间 |
| `paidAt` | 支付时间 |
| `deliveredAt` | 配送完成时间 |
| `completedAt` | 订单完成时间 |
| `cancelledAt` | 取消时间 |
| `dueDate` | 截止日期（仅日期 `YYYY-MM-DD`） |
| `expiredAt` / `expiryDate` | 过期时间/日期 |
| `joinedAt` | 加入时间 |
| `acceptedAt` | 接单时间 |

### B.2 金额字段

所有金额字段为 `number` 类型，保留 2 位小数，单位为元（¥）：

- `totalAmount` 订单总额
- `deliveryFee` 配送费
- `paidAmount` 已缴金额
- `coinBalance` 物业币余额
- `amount` 通用金额

### B.3 积分字段

所有积分字段为 `number` 类型，必须为整数：

- `pointBalance` 积分余额
- `pointUsed` 使用积分
- `pointEarned` 获得积分
- `pointDeducted` 抵扣积分

### B.4 标识字段

所有 ID 字段为 `string` 类型，使用前缀 + 随机字符串格式（详见 1.5）。
