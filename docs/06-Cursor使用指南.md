如果你不想一次性提供所有文档，可以按以下步骤：

## 3. 常见场景提示词

### 3.1 开发认证模块

```
请帮我开发认证模块，包括：

1. 微信小程序登录接口
2. JWT Token生成和验证
3. Token刷新机制
4. 权限校验拦截器

业务规则：
- 使用微信openid登录
- Access Token有效期1小时
- Refresh Token有效期7天
- Token存于内存（不存localStorage）

参考文档：
- 03-API接口设计.md（认证接口）
- 01-后端开发规范.md（JWT实现）
```

```
4. 积分记录查询

业务规则：

参考文档：
```

## 4. 注意事项

### 4.1 文档顺序
1. 先让Cursor阅读项目概览，了解项目全貌
2. 再阅读开发规范，了解代码结构
3. 最后阅读具体模块的设计文档

### 4.2 提示词技巧
1. 明确说明要开发的模块
2. 提供业务规则和约束条件
3. 引用相关文档作为参考
4. 要求Cursor遵循项目规范

### 4.3 代码审查
1. 每次生成代码后都要审查
2. 检查是否符合项目规范
3. 检查是否有潜在问题
4. 必要时要求Cursor优化

### 4.4 迭代开发
1. 先开发核心模块（P0）
2. 再开发增强模块（P1）
3. 最后开发扩展模块（P2）
4. 每个模块开发完成后进行测试
