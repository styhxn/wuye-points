给非技术同事的版本

一张图，看懂整个系统

不管系统里有多少角色，其实只有四件事：住户花钱、商家卖货、物业管事、平台定规则。 其他的“楼长、经理、组长、店主、代理”，都是住户身上的第二个身份，订单完成后按约定分钱。

住户 / 业主 商家 / 骑手 / 技工 物业 平台 钱和审核 额外身份

先看全局：四层关系

从上往下看，平台管物业，物业管小区，住户在小区里生活，商家和骑手来服务。

平台
定规则的人建物业公司、定分钱比例、开关资金功能、看全平台总账。
↓ 给物业定规则、定比例
物业
管小区的人管住户和房间、建物业费账单、审商家和身份、处理退款和提现、发公告。
↓ 服务小区、审核申请
住户
花钱的人选小区、逛商城、下单、缴物业费、报事、发帖、看公告。
⇄
服务
干活的人商家卖货，骑手送货，技工上门做家政和维修。
住户下单付钱，商家/骑手/技工把东西和服务送到住户手里。
那“楼长、经理、统筹、板块、个体、组长、店主、代理”是什么？ 他们不是另一套 App，也不是独立账号；他们首先是住户，然后身上多了一个身份。订单完成后，系统按这个身份的比例，把物业那部分钱再分给他们。

一个订单的一生

住户从下单到平台分钱，中间一共 8 步。看懂这条线，就看懂了 80% 的系统。

1逛店看商家、看商品、看价格
→
2下单选商品、填地址、用优惠券
→
3付钱积分 / 物业币 / 微信 / 混合
→
4商家接单确认订单、选择自己送还是平台送
5送货 / 上门商家自送、骑手配送、技工上门
→
6确认收货住户确认，或超时自动确认
→
7系统分钱按比例分给平台、物业、管理团队、骑手
→
8提现商家和各类身份申请提现，人工或微信打款
如果住户不满意：住户申请退款 → 订单进入“退款中” → 物业或平台审核 → 通过就退积分/物业币/现金，驳回就继续履约。
注意：商家自己不能点“同意退款”，退款审核在物业或平台后台。团购单商家可以“核实拒绝”，那会直接取消并退款。

住户怎么用

住户是整个系统的入口，也是最基础的身份。

住户 / 业主

所有人一开始都是住户

微信进入，选小区，之后可以买东西、缴物业费、看公告、发帖、叫服务。

1微信进入授权登录，第一次要选物业公司
→
2选小区 / 房号楼栋房号由物业维护，住户可申请变更
→
3完善资料姓名、头像、年龄等，可领一次性奖励
→
4日常使用逛商城、缴物业费、看公告、发帖、叫服务
5下单付钱积分、物业币、微信或混合支付
→
6收货 / 确认确认后订单完成，系统开始分钱
→
7攒积分消费后返积分，下次可以抵钱
→
8组建家庭一人开家，全家共用积分和物业币
退款怎么走：住户申请 → 物业/平台审核 → 退积分、物业币或现金。注意：住户自助退款有一个总开关，目前默认是关着的。
家庭要特别注意：创建家庭时，户主自己的积分和物业币会全部搬进“家庭池”；之后新发放的物业币进个人余额，积分仍进家庭池，消费默认先家庭后个人。成员退出时按人数平均分，不是按谁贡献多。

商家怎么做生意

商家不是单独的账号，而是“住户账号 + 一个店铺”。审核通过只建店，账号要另外开。

商家

卖货、送货、收钱

从申请开店，到订单完成、提现，完整 8 步。

1申请开店填店名、类目、电话、地址、配送费
→
2等审核物业或平台审核，通过后店铺才能营业
→
3上架商品设价格、库存、会员价
→
4收到订单住户付完钱，订单进入商家后台
5选配送方式自己送，或交给平台骑手
→
6发货 / 送达商家确认送达，或骑手完成配送
→
7订单完成住户确认收货，或超时自动确认
→
8申请提现可提现 = 已完成订单收入 − 已提现
商家要记住三件事：① 退款不是商家审，是物业/平台审；② 被冻结后商品会下架，下单也会被拒；③ 配送费归店铺，但平台会抽一部分配送分成。

物业怎么管

物业负责小区里的日常运营，也是大部分审核的“最后一关”。

物业管理员

只管自己物业

管住户、管房间、管商家、管账单、管内容、审退款和提现。

1住户入住建住户、分房间、改楼栋单元房号
→
2建物业费账单物业费、停车费、水电费
→
3审商家和身份商家、楼长、经理、负责人、组长、小店、代理
→
4日常运营公告、论坛、咨询、食堂、配送规则
5处理售后退款审核、提现审核、物业币兑换审核
→
6看数据住户、订单、分成、物业费、投诉
→
7月底对账看分成记录，申请物业公司提现
→
8平台审核物业公司提现由平台审批打款
物业不能做的事：不能改分钱比例，不能看别的物业的数据，不能改平台级开关。这些只有平台能改。

平台怎么管

平台不直接服务住户，主要负责“开城”和“定规则”。

平台管理员

管所有物业

建物业、定比例、开资金功能、审大额提现、看全平台总账。

1建物业公司填资料，同时建第一个小区
→
2定分钱比例平台、物业、管理团队各拿多少
→
3开资金功能现在先记账，还是以后接微信直接分钱
→
4建物业管理员给物业一个能登录的后台账号
5审大额提现物业公司的分成提现由平台审批
→
6看总账全平台交易、提现、分钱、退款
→
7处理异常手动调账、补分账、冲正
→
8上线检查关测试模式、改默认密码、确认资金开关

加在住户身上的身份

他们不需要另外注册。被任命或被审核通过后，“我的”页面就会多一个入口。

单元楼长物业任命
1物业/平台指定某栋某单元的楼长
2楼长身份生效，但仍是住户
3订单完成，按比例分到楼长
4在“我的”里看收益、申请提现
钱从哪来：物业分成的钱里，再按楼长比例分一部分。
物业经理物业任命
1每个物业公司只能有一位经理
2经理可以管楼长、看收益
3经理的钱从楼长那份里再抽
4在“我的”里申请提现
钱从哪来：楼长拿到的钱里，再按经理比例分一部分。
统筹物业/平台任命
1负责整个物业公司的管理盘
2可以加板块、加个体、审商家加入
3订单完成，拿管理盘剩下的大头
4在工作台看收益、申请提现
钱从哪来：管理盘分给板块之后，剩下的归统筹。
板块负责人物业/平台/统筹任命
1负责一个板块的商家和个体
2可以审个体新增商家、看营收
3订单完成，按板块比例分钱
4在工作台申请提现
钱从哪来：管理盘里先分一块给板块，再分给个体，剩下是板块负责人的。
个体负责人自己申请 + 审核
1住户在“我的”里申请，选一个板块
2物业/平台审核通过
3可以改名下商家的分成、看营收
4订单完成，按比例分钱、提现
钱从哪来：板块那块钱里，再按个体比例分一部分。
活动组组长自己申请 + 审核
1住户申请，物业/平台审核
2通过后自动开一家“组长小店”
3可以建活动组、收成员、发活动
4靠小店的商品货款赚钱、提现
钱从哪来：商品货款，不是分账；订阅费目前不进组长口袋。
注意：组长不在分钱名单里，别按“组长拿分成”去验收。
业主小店自己申请 + 交保证金
1业主申请，先交 500 元保证金
2物业/平台审核通过
3从一级代理的货源里选品转卖
4订单完成，赚进货价和卖价之间的差价
钱从哪来：差价 + 货款按件结算，不走普通商家那套分钱。
一级代理自己申请 + 审核
1任何登录用户都能申请
2审核通过后有自己的货源和拿货记录
3把货供给业主小店去卖
4订单完成，按进货价拿货款
钱从哪来：拿货款，不是拿佣金。
注意：如果只是普通住户身份，目前没有提现入口。
快递员物业/平台开账号
1物业/平台给账号，或快递负责人添加
2在抢单大厅看待送订单
3抢单 → 取货 → 送达
4拿配送费，申请提现
钱从哪来：配送费减去平台配送分成。
技工物业/平台开账号
1物业/平台给账号，自动有技工店
2在任务里看服务单
3上门 → 开始 → 完成
4按服务单金额拿钱、提现
钱从哪来：已完成服务单的金额。
还有两个“历史身份”：区域负责人、项目负责人。它们只在组织架构里展示，目前不参与订单分钱。如果产品要求这两级也分钱，需要另外开发。

钱怎么分

先记住一句话：住户付的钱，先扣商家的“佣金”，佣金再分给各方，剩下的才是商家货款。

1
住户付 100 元可能是现金，也可能是积分、物业币，或者混合支付。
↓
2
先算“佣金”假设商家抽佣 10%，佣金就是 10 元。积分/物业币的成本会先从佣金里扣。
↓
3
10 元佣金再分平台、物业、管理团队、楼长、经理、骑手，各按比例拿。
平台平台服务费
物业小区运营分成
管理团队统筹 / 板块 / 个体
个人楼长 / 经理 / 骑手
↓
4
商家留下 90 元货款商家不是分钱接收方，货款是留给自己；订单完成后可以申请提现。
用积分/物业币付款会怎样：系统要先把积分/物业币的成本从佣金里扣掉。如果成本比佣金还高，这一单就没有钱可分，差额由物业的池子吸收。

现在和以后：三种资金方式

这三种方式不要同时开，否则会重复出款。

现在 钱先进平台，平台记账

用户付款进平台商户号。平台内部记一笔账，商家提现靠人工打款。系统默认就是这样。

方案 A 微信直接分给各方

用户在平台商户号付款并冻结，订单完成后微信直接把钱分给平台、物业、管理团队、楼长、经理、骑手。

方案 B 钱直接进商家

用户付款直接进商家的微信子商户号，平台只分佣金和配送费，货款留在商家，售后窗口到期再解冻。

现在还不能做的事

这些不是“操作不对”，是代码还没接通。验收前先和产品确认，别当成 bug 提。

普通住户不能提现积分和物业币都不能直接换现金；只有商家能把收到的物业币申请兑换现金。
商家不能自己同意退款退款由物业或平台审核；商家只能拒团购核实。住户自助退款开关默认还关着。
社区管理员没有后台系统里有这个角色名，但目前没有任何实际管理权限，先当预留角色。
食堂余额只显示不扣食堂“定向余额”在订单页能看到，但下单时不会真的扣减。
活动组长没有订阅费收入组长靠自己的小店卖货赚钱；活动组的订阅费目前不进组长口袋，也不参与分钱。
物业分成账户不会自动加钱订单完成会记录分成，但物业公司的结算账户目前只扣不提，提现前可能需要平台手动调账。
普通住户身份的一级代理提不了现代理赚的是货款，但提现入口只放行商家、组长、技工；纯住户身份会被拦。
区域 / 项目负责人不分钱这两个身份只在组织架构里展示，订单分钱代码没有接。

最后，记住三句话

1
住户是底座

楼长、经理、组长、店主、代理，都是加在住户身上的“第二身份”，不是另一套账号。

2
三种钱不一样

积分是消费返利，物业币是小区储值，现金走微信；三者不能直接互换。

3
各干各的活

平台定规则，物业管小区，商家做买卖，管理团队和骑手按比例分钱。
