# 物业积分服务系统 - 测试用例文档

> 本文档基于 PRD 验收标准转化而来，按 P0/P1/P2 优先级组织，覆盖功能、数据隔离、并发边界、安全四大测试维度。

## 1. 文档说明

### 1.1 用例编号规则
| 前缀 | 说明 |
|------|------|
| TC-P0-XXX | P0 核心测试用例 |
| TC-P1-XXX | P1 增强测试用例 |
| TC-P2-XXX | P2 增值测试用例 |
| TC-ISO-XXX | 数据隔离专项测试 |
| TC-CON-XXX | 并发与边界测试 |
| TC-SEC-XXX | 安全测试 |

### 1.2 优先级定义
| 优先级 | 含义 | 准入条件 |
|--------|------|----------|
| P0 | 阻塞核心业务，必须通过方可上线 | 主流程闭环 |
| P1 | 增强功能，影响完整体验 | 上线后两周内修复 |
| P2 | 增值功能，可分批迭代 | 按排期处理 |

### 1.3 测试步骤格式
> 步骤中使用 `→` 表示顺序操作，`&&` 表示并行验证。
