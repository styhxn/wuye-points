# 数据库设计 - 物业积分服务系统

> 共 49 张表，覆盖 PRD V4.1 全部需求（P0/P1/P2）

## 1. 设计原则

- 主键 `id`：`VARCHAR(32)`，前缀+随机字符串（如 `res_b7m9x1`）
- 时间字段：`created_at` / `updated_at`，`TIMESTAMP`
- 金额：`DECIMAL(10,2)`；积分：`INT`；比例：`DECIMAL(5,4)`
- 枚举：`VARCHAR` 字符串常量（snake_case）
- 多物业公司数据隔离：所有业务表含 `property_company_id`，Repository 层强制过滤
- 乐观锁：订单等并发表含 `version INT`

## 2. 基础架构模块

### 2.1 物业公司表 (property_companies)

```sql
CREATE TABLE property_companies (
    id VARCHAR(32) PRIMARY KEY COMMENT 'pc_xxxxxxxx',
    name VARCHAR(100) NOT NULL COMMENT '名称',
    logo_url VARCHAR(500) COMMENT 'Logo',
    contact_phone VARCHAR(20) COMMENT '联系电话',
    address VARCHAR(200) COMMENT '地址',
    -- 四级分成比例（各公司可自行设定）
    property_share_rate DECIMAL(5,4) DEFAULT 0.3000 COMMENT '物业分成比例',
    coordinator_share_rate DECIMAL(5,4) DEFAULT 0.7000 COMMENT '统筹分成比例',
    sector_leader_rate DECIMAL(5,4) DEFAULT 0.1000 COMMENT '板块负责人比例（从统筹中抽取）',
    individual_leader_rate DECIMAL(5,4) DEFAULT 0.0000 COMMENT '个体负责人比例（从板块中抽取）',
    -- 物业币配置
    coin_display_enabled BOOLEAN DEFAULT TRUE COMMENT '物业币卡片全局显示',
    coin_issue_mode VARCHAR(20) DEFAULT 'auto' COMMENT '发放模式：auto/manual_approval',
    coin_expiry_days INT DEFAULT 365 COMMENT '物业币有效期天数',
    coin_freeze_default BOOLEAN DEFAULT FALSE COMMENT '新用户物业币默认冻结',
    -- 配送配置
    delivery_base_fee DECIMAL(10,2) DEFAULT 0.00 COMMENT '配送起步价',
    delivery_courier_share_rate DECIMAL(5,4) DEFAULT 1.0000 COMMENT '快递员配送费分成比例',
    delivery_courier_per_order DECIMAL(10,2) DEFAULT 0.35 COMMENT '快递员每单报酬',
    -- 提现配置
    withdrawal_fee_rate DECIMAL(5,4) DEFAULT 0.0060 COMMENT '提现手续费率',
    -- 其他配置
    point_to_fee_rate DECIMAL(10,4) DEFAULT 0.0100 COMMENT '积分抵扣物业费比率（100积分=1元则0.01）',
    two_year_clear_enabled BOOLEAN DEFAULT TRUE COMMENT '2年欠费积分清零开关',
    neighbor_daily_contact_limit INT DEFAULT 2 COMMENT '邻居私聊每日限制',
    status VARCHAR(20) DEFAULT 'active' COMMENT 'active/inactive',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='物业公司表';
```


### 3.3 商家-物业参数配置表 (merchant_property_configs)

同一商家在不同物业公司下独立设定：抽佣比例/积分兑换比/业主折扣价/物业币返现比。

```sql
CREATE TABLE merchant_property_configs (
    id VARCHAR(32) PRIMARY KEY COMMENT 'mpc_xxxxxxxx',
    merchant_id VARCHAR(32) NOT NULL,
    property_company_id VARCHAR(32) NOT NULL,
    commission_rate DECIMAL(5,4) NOT NULL COMMENT '抽佣比例（0.05=5%）',
    point_exchange_rate DECIMAL(10,4) COMMENT '积分兑换比（200积分=1元则填200）',
    member_discount_price DECIMAL(10,2) COMMENT '业主折扣价',
    coin_rebate_rate DECIMAL(5,4) DEFAULT 0.0000 COMMENT '物业币返现比（仅高抽佣≥20%商家生效）',
    coin_rebate_enabled BOOLEAN DEFAULT FALSE COMMENT '是否启用物业币返现',
    status VARCHAR(20) DEFAULT 'active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (merchant_id) REFERENCES merchants(id),
    FOREIGN KEY (property_company_id) REFERENCES property_companies(id),
    UNIQUE KEY uk_merchant_property (merchant_id, property_company_id),
    INDEX idx_property_company (property_company_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='商家-物业参数配置表';
```

## 18. 索引策略

### 18.1 主键索引
所有表 `id` 为主键。

### 18.2 外键索引
所有外键字段自动创建索引。

### 18.3 业务索引
- 状态字段：`status`, `order_status`, `audit_status`, `payment_status`
- 时间字段：`created_at`, `updated_at`, `expired_at`, `end_date`
- 查询字段：`property_company_id`, `community_id`, `resident_id`, `merchant_id`
- 唯一索引：`openid`, `order_no`, `phone`, `(platform_merchant_id, property_company_id)`

### 18.4 复合索引
- `idx_resident_source`: `(resident_id, source, source_id)` - 积分/物业币记录
- `idx_order_status_time`: `(order_status, created_at)` - 订单状态+时间
- `uk_opinion_family`: `(opinion_box_id, family_id)` - 一户一票
- `uk_resident_date`: `(resident_id, contact_date)` - 邻居私聊限制
