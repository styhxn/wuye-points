## 6. 常用Cursor提示词

### 6.1 创建模块
```

1. Entity实体类
2. Repository接口
3. Service服务类
4. Controller控制器
5. DTO请求/响应类
6. 错误码定义

表结构：
[粘贴SQL]
```

### 6.2 添加接口
```
请为我添加 [接口名称] API接口：
- 请求方式：[GET/POST/PUT/DELETE]
- 路径：/api/v1/[resource]
- 鉴权：Required
- 允许角色：[roles]
- 请求参数：[params]
- 响应格式：[示例]
```

## 10. 开发阶段优先级

### P0 核心模块（必须先开发）
1. 认证模块 (Auth)
2. 业主模块 (Residents)
3. 家庭模块 (Families)
4. 积分模块 (Points)
5. 物业币模块 (PropertyCoins)
6. 商家模块 (Merchants)
7. 订单模块 (Orders)
8. 分成模块 (Distribution)

### P1 增强模块（其次开发）
1. 公告模块 (Announcements)
2. 配送模块 (Deliveries)
3. 消息模块 (Messages)
4. 社区服务模块 (Services)
5. 统筹模块 (Coordinators)

### P2 扩展模块（最后开发）
1. 活动组模块 (ActivityGroups)
2. 意见箱模块 (OpinionBoxes)
3. 社区商城模块 (Products)
4. 报表模块 (Reports)
