# 物业积分服务系统 - 项目概览

> **版本**：PRD V4.1 对齐版 | **文档日期**：2026-07-01 | **数据库表数**：49 张

## 1. 项目定位

物业积分系统（Property Points System）是一款**多物业公司架构**的住宅小区综合服务平台，通过"积分+物业币"双货币体系，将业主的日常生活消费转化为可兑换的积分收益，同时为商家、物业、统筹、板块负责人、个体负责人等角色创造共赢的社区生态。

## 2. 核心业务模型

```
业主消费 → 商家获得订单收入 → 按比例四级分成
                                    ↓
                    物业分成(30%)  +  统筹分成(70%)
                                            ↓
                              板块负责人(从统筹抽10%)  +  个体负责人(从板块剩余中抽)
                                    ↓
                              业主获得积分/物业币（按住户所属物业 T 计算）
```

## 3. 角色体系（8 种角色）

| 角色 code | 角色名 | 说明 | 数据范围 |
|------|------|------|------|
| `platform_admin` | 平台管理员 | 平台级别管理人员 | 全平台（跨物业） |
| `property_admin` | 物业管理员 | 某一物业公司的管理人员 | 本物业公司 |
| `coordinator` | 统筹 | 跨小区运营者（可兼职） | 所属物业的特定板块 |
| `sector_leader` | 板块负责人 | 管理某板块下的商家 | 所属板块 |
| `individual_leader` | 个体负责人 | 管理特定商家 | 所属商家 |
| `merchant` | 商家 | 入驻平台的商户 | 自己的商家记录 |
| `courier` | 快递员 | 小区专职配送人员 | 本物业公司配送单 |
| `resident` | 业主/住户 | 注册时选择物业+小区+楼栋 | 自己/家庭 |

> `activity_leader`（活动组组长）作为 `resident` 的子角色存在。

## 4. 双货币体系（独立运作，不可互兑）

### 4.1 积分体系
- **获取方式**：消费返积分、活动奖励、签到、商家赠送、线下发放
- **使用方式**：积分兑换商品/服务、积分抵扣物业费（100积分=1元）、投票权重
- **特殊规则**：积分不可兑换物业币；家庭共享积分池；2年欠费清零入积分池

### 4.2 物业币体系
- **获取方式**：消费获得（按商家设定比例）
- **使用方式**：支付物业费、购买服务、兑换提现
- **特殊规则**：1物业币=1元；不可兑换积分；可冻结/隐藏；过期清零入积分池

## 5. 分成机制（四级分成 - 核心业务逻辑）

> **重要**：积分按**住户所属物业 T** 计算（非商家所属物业）。详细公式见 `07-业务规则详解.md`。

```
消费金额 P × 商家在该物业的抽佣比例 R_T = 可分利润 D
（D 再扣除积分成本 + 物业币成本 = 实际可分金额 D'）

物业分成    = D' × propertyShareRate       (默认 30%)
统筹分成    = D' × coordinatorShareRate    (默认 70%)
板块负责人  = 统筹分成 × sectorLeaderRate   (默认 10%，从统筹中抽)
个体负责人  = 板块负责人 × individualLeaderRate (默认 0%，从板块中抽)
统筹实收    = 统筹分成 - 板块负责人 - 个体负责人
```

**关键约束**：
- 各物业公司可自行设定四级分成比例（`property_companies` 表的 `property_share_rate` 等字段）
- 商家在不同物业下的抽佣比例独立配置（`merchant_property_configs` 表）
- 负责人不存在时，其份额归统筹/物业

## 11. 关键业务术语表

| 术语 | 说明 |
|------|------|
| 物业 T | 住户所属的物业公司，用于计算积分归属 |
| 平台级商家库 | `platform_merchants` 表，商家基础信息一次录入 |
| 商家挂接 | `merchants` 表，平台商家挂接到各物业公司 |
| 独立参数配置 | `merchant_property_configs` 表，各物业下商家的抽佣比例等独立设定 |
| 积分池 | `point_pools` 表，按物业公司维度，资金由物业公司承担 |
| 三大入池来源 | 兑换比例差额、物业币过期清零、2年欠费清零 |
| 双货币体系 | 积分 + 物业币，独立运作，不可互兑 |
| 家庭制 | 上限 15 人，积分合并到家庭池，一户一票 |
| 四级分成 | 物业30% → 统筹70% → 板块10%（从统筹抽）→ 个体（从板块抽） |
| 数据隔离 | 所有业务表强制 `property_company_id` 过滤 |
