## 快速开始

### 1. 了解项目
首先阅读 `00-项目概览.md`，了解项目定位、业务模型和技术栈。

### 2. 配置Cursor
阅读 `04-Cursor-AI开发流程.md`，配置Cursor开发环境。

### 3. 开始开发
按照以下顺序开发模块：

#### 第一阶段：核心基础（1-2周）✅ 已完成
1. 认证模块 (Auth) - 登录、Token刷新
2. 业主模块 (Residents) - 注册、信息管理
3. 家庭模块 (Families) - 家庭创建、成员管理
4. 积分模块 (Points) - 积分余额、记录查询
5. 物业币模块 (PropertyCoins) - 物业币余额、记录查询
6. 商家模块 (Merchants) - 商家入驻、审核
7. 订单模块 (Orders) - 下单、支付、状态流转
8. 分成模块 (Distribution) - 分成计算、记录查询

#### 第二阶段：业务核心（2周）
1. 公告模块 (Announcements) - 发布、展示、推送
2. 配送模块 (Deliveries) - 抢单、配送、状态更新
3. 消息模块 (Messages) - 发送、接收、已读
4. 社区服务模块 (Services) - 服务发布、预约
5. 统筹模块 (Coordinators) - 统筹入驻、收益统计

#### 第三阶段：增强功能（1-2周）
1. 活动组模块 (ActivityGroups) - 活动创建、报名
2. 意见箱模块 (OpinionBoxes) - 投票、意见征集
3. 社区商城模块 (Products) - 商品管理、库存
4. 报表模块 (Reports) - 数据统计、导出

### 4. 联调测试
开发完成后，与前端进行联调测试。

## 核心业务逻辑

### 分成计算公式
```
消费金额(P) × 商家佣金比例(R) = 可分成金额
                                    ↓
                    物业公司分成(30%) + 统筹分成(70%)
                                    ↓
                    统筹分成中拿出10%给技工负责人
```

### 双货币体系
- **积分**：消费返积分、活动奖励、不可兑换物业币
- **物业币**：消费获得、1物业币=1元、不可兑换积分

### 角色权限
- **业主**：消费、查看收益、投票
- **物业管理员**：全部权限
- **商家**：商品管理、订单管理
- **快递员**：接单、配送
- **统筹**：统筹收益、活动组织
